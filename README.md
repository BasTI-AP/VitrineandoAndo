# VitrineandoAndo
Pagina E-commerce de cotizacion y balance de varias e-commerce

Líder/interactividad/Product Owner: Bastián Bustos

Diseño UI/Interactividad: Walter Paredes

Frontend/Interactividad: Hernán Silva


*OBJ-1: Proveer una plataforma web funcional que permita comparar precios en categorías no cubiertas por SoloTodo.

*OBJ-2: Garantizar un mínimo de 3 o más enlaces a tiendas/sitios externos por cada categoría en la demo.

*OBJ-3: Facilitar la búsqueda y filtrado ágil por categoría, rango de precios y condición (Nuevo / Usado).
